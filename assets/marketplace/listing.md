## English

### Short description

```
Apply clean, consistent designs to your Google Slides tables in one click — borders, colors, alignment and text styles together.
```

### Detailed description

```
Slide Table Styler makes the tables in your presentations look clean and consistent — without formatting cells one by one.

Open the sidebar, pick a design, and click Apply. Borders, background colors, text colors and alignment are set together in one step.

FEATURES
• 4 design presets: Clean Gray, Navy Stripe, Minimal (Rules Only) and Dotted Rows
• Accent color: use each design's own color, pick one of your slide's theme colors, or choose any color
• Apply to the selected table, every table on the current slide, or every table in the presentation
• Smart alignment: keep your existing alignment, and automatically right-align columns that contain only numbers ($1,200 / 12.5% / -300 and more)
• Rows, columns and lines: set a minimum row height, make columns equal width, and switch inner lines to solid, dotted or dashed
• Text settings: font, header and body font sizes, bold columns and a bold header row
• Available in English and Japanese

HOW TO USE
1. Open a presentation in Google Slides.
2. Choose Extensions > Slide Table Styler > Open sidebar.
3. Click inside a table (not needed when applying to a whole slide or presentation).
4. Choose a design and options, then click Apply.
Not happy with the result? Press Ctrl+Z (Cmd+Z on Mac) to undo.

PRIVACY
Slide Table Styler only reads and changes the tables in the presentation you have open, and only when you click Apply. It does not store your content or send it anywhere. Details: https://slide-table-styler.zkuma.com/privacy.html

SUPPORT
Questions, bug reports and feature requests: https://github.com/sok41/slide-table-styler/issues
```

## 日本語

### 短い説明

```
Googleスライドの表に、整ったデザインをワンクリックで適用。罫線・色・揃え・文字の書式をまとめて設定します。
```

### 詳しい説明

```
Slide Table Styler は、Googleスライドの表をワンクリックで見やすく整えるアドオンです。セルを1つずつ書式設定する手間はもう必要ありません。

サイドバーでデザインを選んで「適用」を押すだけで、罫線・背景色・文字色・揃えをまとめて設定できます。

主な機能
・4つのデザイン：クリーン・グレー、ネイビー・ストライプ、ミニマル（横線のみ）、ドット区切り
・アクセントカラー：デザインごとの色のほか、スライドのテーマの色や好きな色を選べます
・適用する範囲：選択中の表／このスライドのすべての表／プレゼンテーション内のすべての表
・揃え：今の揃えをそのまま残しつつ、数値だけの列は自動で右揃え（1,200 / 12.5% / ¥500 / ▲300 など）
・行・列と罫線：行の高さの最小値、列幅の均等化、内側の罫線の実線・点線・破線
・文字の設定：フォント、見出しと本文の文字サイズ、太字にする列、見出し行の太字
・日本語・英語に対応

使い方
1. Googleスライドでプレゼンテーションを開きます。
2. 「拡張機能 > Slide Table Styler > サイドバーを開く」を選びます。
3. 表の中をクリックします（スライド全体・プレゼンテーション全体に適用する場合は不要です）。
4. デザインと設定を選び、「適用」を押します。
元に戻したいときは Ctrl+Z（Mac は ⌘+Z）を押してください。

プライバシー
Slide Table Styler は、「適用」を押したときに、開いているプレゼンテーションの表だけを読み取って変更します。内容を保存したり、外部に送信したりすることはありません。詳しくは https://slide-table-styler.zkuma.com/privacy.html をご覧ください。

サポート
ご質問・不具合の報告・機能の要望は https://github.com/sok41/slide-table-styler/issues へお寄せください。
```
