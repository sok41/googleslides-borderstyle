Privacy Policy

Effective date: September 30, 2026

This Privacy Policy explains how Slide Table Styler (the "Add-on"), a Google Slides add-on developed by sok41 (the "Developer"), accesses, uses, and handles your data.

Summary

  • The Add-on only works on the presentation you have open, and only changes it when you click Apply.
  • The Add-on does not store your content and does not send it to the Developer or any third party.
  • The Add-on does not use cookies, analytics, or advertising.

Data the Add-on accesses

The Add-on runs on Google Apps Script under your Google account. It accesses the following data only while you use it:

  • Tables in the open presentation — the number of rows and columns, merged cells, column widths, and the text in each cell. The text is read only to decide how to format it (for example, to skip empty cells and to find columns that contain only numbers).
  • Theme colors of the current slide — read when the sidebar opens, to offer them as accent color choices.
  • Your language setting — used to show the menu and messages in Japanese or English.

How the Add-on uses the data

The data is used only to provide the Add-on's features: applying borders, background colors, text styles, alignment, row heights, and column widths to the tables you choose. The Add-on does not use your data for any other purpose.

Google OAuth scopes

ScopeWhy the Add-on needs it
https://www.googleapis.com/auth/presentations To read the tables in the open presentation and change their formatting when you click Apply. Table borders can only be changed through the Google Slides API, which requires this scope. The Add-on only works on the presentation you have open.
https://www.googleapis.com/auth/script.container.ui To show the Add-on's menu and sidebar inside Google Slides.

Storage and sharing

  • The Add-on does not save your content or settings. All processing happens on Google's servers while the Add-on runs, and nothing is kept afterward.
  • The Add-on does not transfer your data to the Developer or to any third party, does not sell it, and does not use it for advertising or to train AI or machine learning models.
  • If an error occurs, a technical error message may be recorded in Google Cloud Logging so the Developer can fix problems. These messages describe the error (and may include internal identifiers of slide objects) but not the text of your tables. Google also records basic execution information, such as the time and whether it succeeded. These records are deleted automatically according to Google Cloud's retention settings.

Limited Use

Slide Table Styler's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

You can uninstall the Add-on from Google Slides at any time (Extensions → Add-ons → Manage add-ons). You can also remove its access from your Google Account at Third-party apps & services. Because the Add-on keeps no data, there is nothing else to delete.

This website

This website is hosted on GitHub Pages. GitHub may collect technical information such as IP addresses when you visit; see the GitHub General Privacy Statement. This website itself does not use cookies or analytics.

Changes to this policy

If this policy changes, the updated version will be posted on this page with a new effective date.

Contact

For questions about this policy, please open an issue on GitHub Issues.

プライバシーポリシー

施行日：2026年9月30日

このプライバシーポリシーは、sok41（以下「開発者」）が提供する Googleスライドのアドオン Slide Table Styler（以下「本アドオン」）が、データにどのようにアクセスし、どのように扱うかを説明するものです。

概要

  • 本アドオンは、開いているプレゼンテーションだけを対象にし、「適用」を押したときにだけ変更します。
  • 本アドオンは、内容を保存せず、開発者や第三者に送信しません。
  • 本アドオンは、Cookie、アクセス解析、広告を使いません。

本アドオンがアクセスするデータ

本アドオンは、利用者の Google アカウントのもとで Google Apps Script 上で動作し、利用中に限り次のデータにアクセスします。

  • 開いているプレゼンテーションの表：行と列の数、結合したセル、列幅、各セルの文字。文字は書式の決め方にだけ使います（空のセルを飛ばす、数値だけの列を見つけるなど）。
  • 表示中のスライドのテーマの色：サイドバーを開いたときに読み取り、アクセントカラーの候補として表示します。
  • 言語の設定：メニューやメッセージを日本語・英語のどちらで表示するかを決めるために使います。

データの利用目的

データは、本アドオンの機能（選んだ表に罫線・背景色・文字の書式・揃え・行の高さ・列幅を適用すること）を提供するためにだけ使います。それ以外の目的には使いません。

Google OAuth のスコープ

スコープ必要な理由
https://www.googleapis.com/auth/presentations 「適用」を押したときに、開いているプレゼンテーションの表を読み取り、書式を変更するため。表の罫線は Google Slides API でしか変更できず、この API にはこのスコープが必要です。本アドオンは開いているプレゼンテーションだけを対象にします。
https://www.googleapis.com/auth/script.container.ui Googleスライドの中に、本アドオンのメニューとサイドバーを表示するため。

保存と共有

  • 本アドオンは、内容や設定を保存しません。処理は本アドオンの実行中に Google のサーバー上で行われ、終了後に何も残しません。
  • 本アドオンは、データを開発者や第三者に送信せず、販売せず、広告や AI・機械学習モデルの学習に使いません。
  • エラーが起きた場合、開発者が不具合を直すために、技術的なエラーメッセージが Google Cloud Logging に記録されることがあります。これはエラーの内容を示すもので（スライド内のオブジェクトの内部 ID を含むことがあります）、表の文字は含みません。また Google は、実行日時や成功・失敗などの基本的な実行情報を記録します。これらの記録は Google Cloud の保持期間の設定に従って自動で削除されます。

Limited Use（利用の制限）

Slide Table Styler による Google API から受け取った情報の利用と転送は、Limited Use の要件を含む Google API サービスのユーザーデータに関するポリシーに従います。

アクセス権の削除

本アドオンは、Googleスライドの 拡張機能 → アドオン → アドオンを管理 からいつでもアンインストールできます。また、Google アカウントのサードパーティのアプリとサービスからアクセス権を削除できます。本アドオンはデータを保存しないため、ほかに削除が必要なものはありません。
